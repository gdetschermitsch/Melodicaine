Install on iPhone or iPad
  1. Open this exact MelodicaineStudio page in Safari.
  2. Tap Safari’s Share button (square with an upward arrow). On some layouts, tap the page menu first, then Share.
  3. Scroll the action sheet and choose Add to Home Screen.
  4. Turn on Open as Web App when that option is shown, then tap Add.
  5. Close Safari, launch MelodicaineStudio from its new Home Screen icon, and import music from inside that installed copy.
Important iPhone limitation

iOS does not let this web app browse or continuously use a music folder. Folder import is unavailable, and imported audio is copied into Safari-managed website storage. Large permanent libraries require an Android/desktop browser or a native iPhone application.

MelodicaineStudio

Quick Guide

Build a private, polished music studio directly inside your browser.

Your library stays on this device.Import, organize, play, queue, and follow synchronized lyrics without uploading your music to MelodicaineStudio.
01

Quick start

  1. Import music.Choose album folders for automatic grouping, or import individual MP3, VTT, and artwork files.
  2. Browse your studio.Open Artists, Albums, or Tracks and use Search to find music instantly.
  3. Play and organize.Use the player controls, queue songs, create playlists, or add favorites to LovedPlaylist.
  4. Show lyrics.Matching WebVTT files follow playback automatically and can be opened from the player.
  5. Protect the library.Use Protect local library in Manage when your browser supports persistent storage.
02

Studio features

  • Private local libraryMusic remains in browser-managed storage on this device.
  • Smart album importReads MP3 metadata, embedded covers, folder artwork, and matching lyrics.
  • Artist and album organizationAutomatically builds clean library views from imported metadata.
  • Synchronized lyricsWebVTT lines highlight with the current playback position.
  • Playlists and LovedPlaylistCreate, rename, reorder, and manage custom song collections.
  • Full queue controlsAdd, duplicate, remove, reorder, shuffle, and repeat tracks.
  • Custom studio appearanceAdjust colors, interface scale, graphics scale, text scale, and zoom from Settings.
  • Installable web appInstall supported versions for a focused app-style experience.
Best import structure:Keep each album in its own folder with MP3 tracks, optional matching .vtt files, and a cover image named cover, folder, or front.
